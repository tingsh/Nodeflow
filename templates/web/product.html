Hardened Edge & Network Resilience

Our industrial gateway runs directly on Raspberry Pi CM4 architectures, engineered specifically to prevent telemetry data loss on unstable factory floors.

  • 3-Tier Multi-WAN Watchdog: Automatically switches route metrics between Ethernet (primary), Wi-Fi (backup), and 4G/LTE (fallback) using nmcli routing.
  • Zero-Downtime Blue/Green OTA: Upgrade edge logic configurations side-by-side without interrupting Modbus TCP polling loops.
  • Offline Telemetry Cache: Spool data to local storage during WAN disconnects and sync back to TimescaleDB automatically upon healing.
